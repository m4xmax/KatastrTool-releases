# Katastr — stažení

Aplikace pro vyhledání nemovitosti podle adresy (Windows).

## Stáhnout

**[➡ Stáhnout nejnovější verzi](https://github.com/m4xmax/KatastrTool-releases/releases/latest)**

Stáhněte `Katastr-Setup-<verze>.exe`, nainstalujte a spusťte ze zástupce „Katastr".

### „Neznámý vydavatel" při instalaci

Aplikace není podepsaná placeným certifikátem, takže Windows SmartScreen při
prvním spuštění ukáže modré okno „Systém Windows ochránil váš počítač". Klikněte
na **Další informace → Přesto spustit**. Není to vir, jen nepodepsaná aplikace.

### Licence

Při prvním spuštění zadáte jméno a licenční číslo. Licence je vázaná na počítač.
Pokud ji nemáte nebo appku přenášíte na jiný počítač, napište si Maxovi o novou.

### Aktualizace

Appka se aktualizuje sama při startu, nemusíte dělat nic.
